Work

Source is on GitHub for all of it.

  1. 01 CodelessEngine A 2D game engine with a visual editor. You lay out a game, give things behaviours and hit play, no code required. C++20 · OpenGL 4.1 · Box2D · wxWidgets ↗
  2. 02 Block Blast RL Agent PPO with action masking, trained through self-play until it plays Block Blast better than I do. Python · PyTorch ↗
  3. 03 PseudonameGames The Roblox games I make. 4 out so far with 46k visits between them, and 1,267 members in the community. Luau · Roblox Studio ↗
  4. 04 Scenify Pulls the unique meshes out of an FBX/OBJ/GLB scene, exports them as GLB, and writes the Lua that rebuilds the whole scene in Roblox Studio. Python · Roblox Studio ↗
  5. 05 Ghost-Keys An auto-typer that sends input through low-level Windows APIs, so to the OS it looks like someone typing. Python · Win32 ↗
  6. 06 AI Talking Board An Ouija board with a language model on the other side. Ask it something and the planchette answers. JavaScript ↗
  7. 07 Block Blast Solver Takes a board and a hand of pieces and works out where they should go. JavaScript ↗
  8. 08 BroBot An assistant that is confidently wrong about everything and calls you bro far too often. Comes with a talking avatar. JavaScript ↗
  9. 09 Murder at Blackwood Manor A text adventure murder mystery. Search the manor, question the suspects, name the killer. Python ↗
  10. 10 TikTok Repost Logger Watches an account and keeps a log of what it reposts. Python ↗
